// FAQ

Good to know

Is it safe?

CYBERDECK only changes settings for your own Windows user account, using standard Windows settings. Every option can be switched back with the same toggle.

Why does Windows or my antivirus warn me?

The app is a new, unsigned program packaged with PyInstaller, so SmartScreen or antivirus can flag it by mistake. Choose “More info”, then “Run anyway” if you trust the source.

Does it need administrator rights?

Normally no. Most options change per-user settings.

Why does Explorer restart when I toggle something?

Some Windows settings only apply after Explorer restarts. The app does it for you and the screen may flicker for a second. Open File Explorer windows will close.

Which Windows versions work?

Windows 10 and 11. A few options, like centered taskbar and the classic menu, are for Windows 11.
